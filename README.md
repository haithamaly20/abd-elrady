# شقة عبد الراضي — نظام الإدارة المتكامل

تطبيق ويب قابل للتثبيت (PWA) لإدارة حجوزات الشقة، يعمل على الكمبيوتر والهاتف، ويتزامن مباشرة مع Google Sheets.

## محتويات المجلد

```
index.html                  ← التطبيق نفسه (كل شيء بداخله)
manifest.json                ← بيانات التطبيق (الاسم، الألوان، الأيقونات)
sw.js                        ← Service Worker (يسمح بالفتح كتطبيق وبسرعة أكبر)
icons/
  icon-192.png
  icon-512.png
  icon-maskable-512.png
  apple-touch-icon.png
```

**مهم:** هذه الملفات الأربعة (`index.html` + `manifest.json` + `sw.js` + مجلد `icons`) لازم ترفعهم **مع بعض** في نفس المجلد، علشان ميزة التثبيت تشتغل. لو رفعت `index.html` لوحده هيفتح ويشتغل عادي في المتصفح، بس مش هيظهر زرار "تثبيت".

---

## 1) رفع المشروع على GitHub

1. ادخل على [github.com](https://github.com) واعمل حساب لو مفيش عندك.
2. اضغط **New repository** واختار اسم زي `abdulradi-app` (أو أي اسم).
3. اختار الإعداد **Public**، وسيب باقي الخيارات زي ما هي، واضغط **Create repository**.
4. في صفحة الريبو الجديدة، اضغط **uploading an existing file**.
5. اسحب المجلد كامل (الملفات الأربعة + مجلد `icons` بمحتوياته) وارفعهم، ثم اضغط **Commit changes**.

> لو عندك Git على جهازك، بديل أسرع:
> ```bash
> git init
> git add .
> git commit -m "أول نسخة من التطبيق"
> git branch -M main
> git remote add origin https://github.com/USERNAME/abdulradi-app.git
> git push -u origin main
> ```

## 2) تفعيل GitHub Pages (عشان يبقى ليك رابط فعلي)

1. في صفحة الريبو، روح لـ **Settings** (من القائمة العلوية).
2. من القائمة الجانبية، اختار **Pages**.
3. تحت **Build and deployment** → **Source**، اختار **Deploy from a branch**.
4. اختار **Branch: main** و **Folder: / (root)**، ثم **Save**.
5. استنى دقيقة أو اتنين، وهيظهر لك رابط شبه:
   ```
   https://USERNAME.github.io/abdulradi-app/
   ```
   ده رابط تطبيقك الدائم، افتحه من أي جهاز.

---

## 3) فتح التطبيق وتثبيته

### على الكمبيوتر (Chrome / Edge)
- افتح الرابط، هتلاقي أيقونة **تثبيت** ⬇️ في شريط العنوان (يمين مربع البحث).
- اضغط عليها → **تثبيت**. التطبيق هيفتح في نافذة منفصلة زي أي برنامج عادي، وهيتحط له اختصار على سطح المكتب.

### على الأندرويد (Chrome)
- افتح الرابط، هيظهر إشعار **"إضافة إلى الشاشة الرئيسية"** تلقائياً، أو من قائمة المتصفح (⋮) اختار **تثبيت التطبيق / Add to Home screen**.
- هيبقى ليك أيقونة على الشاشة الرئيسية تفتح التطبيق زي أي تطبيق عادي.

### على الآيفون (Safari)
- افتح الرابط في Safari (لازم Safari تحديداً، مش أي متصفح تاني).
- اضغط زرار **المشاركة** (المربع وفوقه سهم) → **إضافة إلى الشاشة الرئيسية / Add to Home Screen**.

## ملاحظات مهمة

- **المزامنة مع Google Sheets** شغالة بنفس الرابط القديم المضمّن في الكود، ومش مرتبطة بمكان استضافة الصفحة — تقدر تفتح التطبيق من أي جهاز وهيتزامن مع نفس البيانات.
- الـ Service Worker (`sw.js`) بيخزن شكل الواجهة بس (الملفات الأساسية) عشان التطبيق يفتح بسرعة، وما بيتدخلش إطلاقاً في مزامنة الحجوزات ولا تصدير Excel ولا الصورة ولا واتساب — كل دي بتتصل بالإنترنت مباشرة زي ما هي.
- لو عدّلت في `index.html` بعدين وعايز التحديث يوصل للأجهزة اللي مثبتة التطبيق: غيّر رقم النسخة `abdulradi-shell-v1` في أول سطر بملف `sw.js` إلى `v2` مثلاً، وارفع التعديل — كده كل جهاز هيسحب النسخة الجديدة تلقائياً.
